## 🚀 Main Projects

## 💍 MarryView

> 결혼 시장의 정보 비대칭 문제를 해결하기 위한
> **영수증 인증 기반 웨딩 리뷰 커뮤니티 플랫폼**

### 🔎 프로젝트 소개

MarryView는 스튜디오, 드레스, 메이크업 업체에 대한 실제 이용자 리뷰를 공유하는 커뮤니티 서비스입니다.
단순 후기 게시판이 아니라, 영수증 인증과 신고 시스템을 통해 신뢰도 높은 리뷰 환경을 만드는 것을 목표로 했습니다.

### ✨ 주요 기능

| 기능           | 설명                               |
| :----------- | :------------------------------- |
| **회원 관리**    | 일반 회원 / 관리자 권한 분리, 로그인 및 회원가입 구현 |
| **커뮤니티 게시판** | 자유게시판, 후기게시판, 댓글 및 대댓글 기능 구현     |
| **업체 관리**    | 스튜디오, 드레스, 메이크업 업체 등록 및 상세 정보 관리 |
| **리뷰 시스템**   | 업체별 리뷰 작성, 별점, 유료 리뷰 열람 구조 설계    |
| **신고 시스템**   | 게시글, 댓글, 리뷰, 업체, 사용자 신고 기능 구현    |
| **찜 기능**     | 관심 업체를 저장할 수 있는 즐겨찾기 기능 구현       |

### 🛠 사용 기술

`Java` `Spring Boot` `JSP` `MyBatis` `MySQL` `Vue.js` `jQuery` `Bootstrap`

## 🎱 CueLinkProject

> 대중 스포츠인 당구를 중심으로 한
> **커뮤니티 및 실시간 소통 플랫폼**

### 🔎 프로젝트 소개

CueLinkProject는 당구 이용자들이 정보를 공유하고 소통할 수 있는 커뮤니티 서비스입니다.
실시간 채팅, 알림, 회원 인증 기능을 중심으로 사용자 간 연결성을 강화하는 데 초점을 두었습니다.

### ✨ 주요 기능

| 기능         | 설명                           |
| :--------- | :--------------------------- |
| **실시간 채팅** | Socket.io 기반 실시간 메시지 송수신 구현  |
| **알림 시스템** | 사용자 활동 기반 실시간 알림 기능 구현       |
| **인증 시스템** | JWT 및 OAuth 2.0 기반 로그인 구조 적용 |
| **게시판 기능** | 게시글 작성, 조회, 수정, 삭제 기능 구현     |
| **데이터 관리** | Oracle DB 기반 회원 및 게시글 데이터 관리 |

### 🛠 사용 기술

`Node.js` `Express` `Socket.io` `JWT` `OAuth 2.0` `Oracle` `JavaScript`
